## Status definitions

- **Proposed** — written and under discussion, not yet built.
- **Implemented** — built and shipped to `develop` (or beyond); this repo has no "Accepted but not started" gap in practice since ADRs here are written close to when the work begins.
- **Superseded** — replaced by a later ADR, which should link back to this one and explain why.
